# Portfolio — modèle GitHub Pages

Portfolio professionnel HTML/CSS/JavaScript, conçu pour être hébergé gratuitement avec GitHub Pages.

## 1. Structure

- `index.html` : contenu du site
- `css/style.css` : design
- `js/script.js` : interactions
- `assets/images/` : images et captures de projets
- `assets/documents/` : page HTML de projet, rapports PDF, etc.

## 2. GitHub Pages

1. Créer un nouveau repository GitHub.
2. Mettre les fichiers du portfolio à la racine du repository.
3. Aller dans `Settings` → `Pages`.
4. Choisir `Deploy from a branch`.
5. Sélectionner `main` et `/ (root)`.
6. Enregistrer.
7. GitHub Pages fournira l'adresse du site.

## Important

Avant publication, vérifier que les rapports et documents que vous mettez en ligne peuvent réellement être diffusés publiquement et qu'ils ne contiennent pas de données confidentielles.
